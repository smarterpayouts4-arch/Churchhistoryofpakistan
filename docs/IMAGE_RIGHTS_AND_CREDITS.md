# Image Rights & Credits

## Rule for this project

A photograph being visible online does **not** mean it can be copied into the website.

This package uses or recommends only images whose reuse terms were clear enough to document. Exact photos for three cathedrals were found online in copyrighted/editorial contexts, but were *not* copied into the package because a reusable license was not verified.

## Permission needed before using a real photo

The following cards intentionally have local SVG placeholders:

- **Faisalabad:** St. John's Cathedral, Gojra
- **Hyderabad:** St. Thomas Cathedral
- **Raiwind:** Central Cathedral of Praying Hands, Lahore

Recommended approach: contact the relevant diocese and ask for a current exterior image with explicit permission to publish on the History: Church of Pakistan website, including permission to crop/resize for web. Record the photographer name and requested credit.

## Credit format

For Creative Commons photos, a good visible credit is:

`Photo: [Creator] / Wikimedia Commons / CC BY-SA 4.0`

Link both the source page and license where practical. If modified/cropped, say `cropped` or `adapted`.

## ShareAlike warning

CC BY-SA images have ShareAlike obligations for adaptations of the image. Keep original attribution metadata and do not strip licensing information from the asset manifest.

This file is operational guidance, not legal advice.

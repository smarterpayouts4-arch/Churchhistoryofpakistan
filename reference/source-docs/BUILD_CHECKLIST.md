# Build / Launch Checklist

## First build
- [ ] Read `README_START_HERE.md`
- [ ] Feed `GROKBOT_MASTER_PROMPT.md` and the full folder to Grokbot/developer
- [ ] Run `python scripts/fetch_cathedral_photos.py` while online
- [ ] Run `python scripts/optimize_images.py`
- [ ] Confirm the curator's public display name and preferred caption
- [ ] Replace the three photo-permission placeholders only with rights-cleared images
- [ ] Enter real interview records; do not publish fictional sample biographies

## Content QA
- [ ] Each historical date has a source

- [ ] Names/titles are checked against records
- [ ] Oral history is labelled as oral history
- [ ] Corrections workflow is visible
- [ ] No private contributor contact data appears publicly

## Technical QA
- [ ] Mobile 320px, 375px, 768px, desktop 1440px tested
- [ ] Keyboard navigation tested
- [ ] Contrast and focus states checked
- [ ] Alt text reviewed
- [ ] Interview transcripts/captions present
- [ ] Images resized and compressed
- [ ] Metadata/OG image added
- [ ] Sitemap/robots/canonical configured
- [ ] Privacy policy and contribution consent language reviewed

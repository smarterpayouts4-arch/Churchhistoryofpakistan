# History: Church of Pakistan — Website Build Package

## START HERE

This package turns **Design 01 — Archival Heritage** into a production-ready plan and starter website for the project:

> **History: Church of Pakistan**  
> *Preserving History • Honouring Our Forefathers • Inspiring Future Generations*

The intended experience is a **living digital archive + documentary magazine**: historical photographs, church buildings, interviews, family records, biographies, dates, documents, and personal memories — presented with the warmth of an archival album and the discipline of a museum collection.

### What is included

- The user-approved **Design 01 reference**
- The supplied founder/curator portrait plus clean homepage crops
- Research on the Church of Pakistan and its **eight dioceses**
- A cathedral/location data file for all eight dioceses
- **Five exact cathedral photographs with verified reusable licensing source URLs**
- Clearly marked placeholders for **three cathedrals where a reusable photo license was not verified**
- A download script that fetches the five reusable cathedral photos into the correct asset folder
- A complete responsive homepage starter (`starter-site/`)
- Design system, content architecture, SEO/accessibility guidance, licensing notes, asset map, and source register
- A ready-to-paste **Grok build prompt**

### Important image-rights note

Do **not** copy photographs from Google, Getty, Tripadvisor, Facebook, news sites, or diocesan sites just because they are visible online. This research found open/reusable exact photos for Karachi, Lahore, Multan, Peshawar, and Sialkot. For Faisalabad/Gojra, Hyderabad, and Raiwind/Lahore, this package intentionally uses “permission pending” placeholders until a photo can be licensed or supplied by the diocese/photographer.

### Recommended build sequence

1. Open `GROKBOT_MASTER_PROMPT.md` and give it to Grokbot together with this full folder.
2. Run `python scripts/fetch_cathedral_photos.py` from the package root while online.
3. Review `docs/IMAGE_RIGHTS_AND_CREDITS.md`.
4. Build from `starter-site/` or use it as the visual/DOM reference.
5. Replace interview/archive placeholders with genuine material.
6. Confirm spellings, dates, captions, and source labels before publishing.
7. Keep a source/credit record for every historical fact and every image.

### One-line design brief

**A dignified sepia-and-burgundy archival homepage that feels like opening a family history album inside a museum — not a generic church template.**
